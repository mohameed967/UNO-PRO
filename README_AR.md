# UNO PRO — نسخة البداية

مشروع أولي للعبة UNO داخل Telegram Mini App.

## ما الموجود حالياً؟
- بوت تيليجرام يستجيب للأمر `/start` ويعرض زر فتح اللعبة بعد ضبط رابط HTTPS.
- واجهة عربية متجاوبة.
- لعبة فردية تجريبية ضد الكمبيوتر.
- أوراق الألوان والأرقام والأوراق الخاصة الأساسية.
- تحقق من Telegram Mini App `initData` في الخادم.
- نقطة فحص `/health`.

## ما الذي لم يكتمل بعد؟
هذه نسخة MVP وليست نسخة UNO نهائية. اللعب الجماعي والغرف وقاعدة البيانات الدائمة ونظام النقاط والبطولات ولوحة الإدارة ما زالت مراحل لاحقة. بيانات المباراة الحالية محفوظة في ذاكرة الخادم وتضيع عند إعادة تشغيله. بعض قواعد الأوراق الخاصة تحتاج استكمالاً واختبارات قبل الإطلاق العام.

## المتطلبات
- Python 3.11 أو أحدث.
- حساب بوت أنشأته عبر BotFather.
- رمز البوت (BOT TOKEN). لا ترسله في المحادثات ولا ترفعه إلى GitHub.

## التشغيل محلياً

1. فك ضغط المشروع.
2. افتح الطرفية داخل مجلد `UNO_PRO`.
3. أنشئ بيئة افتراضية وثبّت الحزم:

   ```bash
   python -m venv .venv
   # Windows:
   .venv\\Scripts\\activate
   # Linux/macOS:
   source .venv/bin/activate
   pip install -r requirements.txt
   ```

4. انسخ `.env.example` إلى ملف باسم `.env`، ثم ضع رمز البوت في `BOT_TOKEN`.
5. اترك `DEV_MODE=true` للتجربة المحلية فقط.
6. شغّل واجهة الخادم:

   ```bash
   uvicorn app:app --reload --host 0.0.0.0 --port 8000
   ```

7. في نافذة طرفية ثانية شغّل البوت:

   ```bash
   python bot.py
   ```

ملاحظة: وضع التطوير يسمح بحساب تجريبي داخل الواجهة، لكنه لا يجعل اللعبة قابلة للفتح من تيليجرام تلقائياً. لتجربة Mini App من تيليجرام تحتاج رابط HTTPS عام، وسنضبطه في مرحلة الاستضافة.

## قبل النشر
- اضبط `DEV_MODE=false`.
- أضف `BOT_TOKEN` و`WEBAPP_URL` كمتغيرات بيئة في منصة الاستضافة.
- اجعل `WEBAPP_URL` رابط HTTPS للخادم.
- لا تضع `.env` في مستودع عام.
- أضف قاعدة بيانات دائمة وتخزين جلسات قبل استخدام عدة لاعبين أو نشر اللعبة للجمهور.


## لوحة الإدارة المستقلة
افتح `/admin` بعد تشغيل الخادم. سجّل الدخول بمتغيري `ADMIN_USERNAME` و`ADMIN_PASSWORD`.
يجب ضبط `SESSION_SECRET` كسلسلة طويلة وفريدة. قاعدة البيانات في هذه النسخة SQLite للتجربة على خدمة واحدة.
تتضمن النسخة تسجيل الدخول، الإحصائيات، قائمة اللاعبين، الحظر وفك الحظر، قائمة المشرفين وسجل العمليات.
الإشعارات الجماعية، إضافة مشرفين بصلاحيات، وإدارة الغرف الحية لم تُنفذ بعد.
لا ترفع `.env` أو ملف قاعدة البيانات إلى GitHub. على الاستضافة أضف القيم كمتغيرات بيئة، واجعل `COOKIE_SECURE=true` مع HTTPS.
